1. Flash T-Display Firmware (Web Serial)

Install the compiled v0.1.0 firmware onto any LilyGO TTGO T-Display (original ESP32, 4 MB flash, 240×135 ST7789). This build includes the cfg.ssp_en = false Bluedroid fix so both original Sony and clone DualShock 3 controllers stay connected.

Web Serial is not available in this browser. Open this page in desktop Google Chrome, Microsoft Edge, or Opera.

Manual download parts: bootloader.bin (0x1000) · partitions.bin (0x8000) · boot_app0.bin (0xe000) · firmware.bin (0x10000)

2. DualShock 3 Host MAC Programmer (Browser Tool)

After flashing, read the ESP32 BT MAC printed on the T-Display screen, plug your DualShock 3 into USB, and write that MAC into the controller.

Browser & OS Driver Caveat: Browsers cannot detach OS kernel drivers.
  • Clone DS3 (045e:028e, WebUSB): Fails on Linux if xpad is loaded (run sudo modprobe -r xpad first) and on Windows unless WinUSB is bound via Zadig. Works directly on macOS if no 360 driver is installed.
  • Original Sony DS3 (054c:0268, WebHID): WebUSB blocks HID interfaces; WebHID attempts feature reports 0xF2/0xF5, which may be blocked by OS HID descriptor checks.
Ready. Connect a controller via USB and choose a tool above.

Guaranteed CLI Fallback (Linux / PyUSB)

PyUSB detaches kernel drivers automatically and works reliably for both original and Xbox-mode clone controllers (see firmware/dualshock3/README.md): 

sudo python3 ds3write.py 10:52:1C:66:50:7E

3. Controls & Architecture Summary (v0.1.0)

Subsystem Hardware / Protocol Role
Drivetrain MCU LilyGO T-Display (ESP32, 240×135 TFT, 4 MB) 3× DRV8833 PWM, 3× Hall sensors, TFT telemetry
Power Rail 2S/3S LiPo + dedicated 5 V buck rail Powers motors & T-Display (onboard 1S Li-Ion port unused)
Remote Control DualShock 3 / Sixaxis (BT Classic, SSP off) Manual drive + START (MAN/AUTO) + SELECT (SAFE_STOP)
Autonomy / Sensors Serial UART (Jetson Nano, own PSU) + I2C port External commands gated behind DS3 safety interlock
